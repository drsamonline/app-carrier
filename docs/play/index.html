Carrier

Carry a message to someone who has no network. It does not promise delivery.

about

There is no Bluetooth, no cable API and no QR camera here. The channel this app actually has is a file you carry yourself. The chain records who handed it on and when — that is a record of hand-offs, not a delivery receipt.

Compose

The body is hashed as you write it. A file whose text no longer matches is refused, not shown as the same message.
