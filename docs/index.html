Carrier

A message carried by hand to someone with no network — and a chain that records who handed it on.

Hashed, not editable

The body is hashed when it is composed. A file whose words have changed is refused rather than shown as the same message — and a hand-off that edits it in memory is refused too.

Counted once

The same carrier handing it on twice is one hop, not two. A chain that inflates itself is not a record.
