Carrier

Carry a message to someone who has no network. It does not promise delivery — it hands you the message and records when it was passed on.

Open Carrier

There is no Bluetooth, no cable API and no QR camera here. The channel this app actually has is a file you carry yourself. That is stated on the page, in the app and in NOTICE, because a transfer app that pretended to find a radio would be lying about the only thing it is for.

Status Built and working: compose a message; a chain of hand-offs, each naming who carried it and when; the body hashed at composition so a file whose text changed is refused rather than shown; a hand-off by the same person twice adds no second hop; and the received view says, in words, that it is a record of hand-offs and not a delivery receipt.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: Bluetooth, cable transfer, QR transfer and any auto-selection between channels. The file is the channel here.

What it does

  • Composes a message for a named person, with the body hashed as it is written.
  • Records each hand-off — who carried it, and when — in order.
  • Exports the message as a small file you carry across yourself, and imports it on the other device.
  • Refuses a file whose body no longer matches the hash, rather than showing it as the same message.

What it will not do

  • Promise delivery. A hand-off is a record that someone took it, not that it arrived.
  • Edit the body. No hop touches the text; the hash proves it.
  • Count the same carrier twice. A person who carries it twice carried it once.
  • Find a radio. No Bluetooth, no cable API, no camera.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA message with no words, or nobody to carry it to, is refused; a hand-off with no carrier is refused.
A changed fileRefused: the body no longer matches the hash recorded when it was composed.
No networkNothing changes — the file is the channel.
Storage full or unavailableNOT SAVED, and the message on screen is unchanged.
